# Skill: Designing UX/UI for Artico

Esta skill está diseñada para transformar el asistente en un experto de diseño UI/UX especializado en colecciones de arte.

## Estructura
- `SKILL.md`: Instrucciones y principios de diseño "Museum/Gallery".
- `resources/design_tokens_template.json`: Tokens visuales predefinidos para mantener el "Vibe" de Artico.

## Uso
Activa esta skill cuando necesites crear componentes visuales, maquetas o flujos de usuario para la gestión de obras de arte.
